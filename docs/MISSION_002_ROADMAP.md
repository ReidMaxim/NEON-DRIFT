# Mission 002 roadmap

1. **Visual depth:** introduce wall grime/repair decals, richer CRT curvature, damp concrete materials, localized steam, softer neon pools, and better puddle masks. Retain small procedural asset footprint.
2. **Broader compatibility evidence:** run native Chrome, Edge, Firefox and Safari acceptance passes; record midrange and integrated GPU measurements at fixed 1080p and all presets. Add GPU timer queries where supported; track frame-interval and GPU time separately.
3. **Spatial scaling:** generate connected blocks using district descriptors; partition instance batches by block, add hysteresis to detail transitions, and maintain collision routes and landmark sightlines.
4. **Animated scenery:** intermittent signs, ventilation fans, distant transit silhouettes, occasional drifting paper, and optional locally synthesized ambience with user-controlled volume.
5. **Interaction:** typed terminal history, local archive entries, several location types and a data-driven registry for future portfolio content. Keep real personal information and external destinations opt-in.
6. **Accessibility/mobile:** remappable controls, sensitivity, reduced-motion/rain toggles, touch look/movement, stronger focus containment and screen-reader descriptions.
7. **Visual regression:** preserve approved viewpoint images per seed, automate short motion recordings, and repeat independent render-only review. Screenshot diffs supplement human judgment; they cannot prove good composition.

Do not add infinite streaming or runtime AI services until a clear experience need justifies the complexity.
